About the Database

Exact Solutions in the Newman–Penrose Formalism

This project is a curated database of exact solutions of Einstein's field equations, drawn primarily from Stephani et al., Exact Solutions of Einstein's Field Equations (2nd ed., Cambridge, 2003). For each metric we record its classical properties (Weyl type, symmetry group, matter source) and its full Newman–Penrose decomposition — Weyl scalars, Ricci components, the cosmological constant Λ, and the twelve complex spin coefficients.

What this database does

For each metric in Stephani's reference, we select a null tetrad adapted to its principal null directions and compute all Newman–Penrose quantities symbolically using SageMath and the SageNP package. Every entry is stored in a structured, machine-readable format that lets you:

  • Search and filter across the full catalog by Weyl type, symmetry group, matter source, and metric form;
  • Query NP scalar patterns — for instance, imposing to isolate algebraically special geometries, or selecting specific vanishing/non-vanishing Ricci components and spin coefficients;
  • Inspect each solution in detail — view the line element in rendered , the full set of Weyl scalars, Ricci components, the cosmological scalar , and all twelve spin coefficients;
  • Download resources — access the associated SageMath notebook and a detailed PDF for every entry to reproduce or extend the calculations.

How to use the site

The site is organized into two main views, accessible from any page via the top navigation bar.

  • Database — the main search interface. Use the left sidebar to narrow results by Weyl type, symmetry group, matter source, or metric form. For finer control, the Attribute Filters let you specify exact vanishing/non-vanishing patterns for Weyl scalars, Ricci components, and spin coefficients. Click any row to open the full detail view for that metric, which shows the rendered line element, all NP quantities, and links to the associated SageMath notebook and PDF.
  • Instructions — the section you are reading now. It contains background material organized into tabs: NP Formalism for a self-contained introduction to the Newman–Penrose framework, Tetrad Choice for the conventions used throughout the database, Using SageMath and SageNP for the computational workflow and code examples, and Papers for publications produced within this project.

Mathematical Framework

The Newman–Penrose Formalism

The Newman–Penrose (NP) formalism, introduced by Ezra Newman and Roger Penrose in 1962, is a null-tetrad based spinorial approach to general relativity that replaces the metric tensor with a set of complex scalar quantities — making the structure of Einstein's field equations and the Bianchi identities far more transparent, especially for algebraically special spacetimes.

Why the NP formalism?

The NP framework offers several practical advantages over the coordinate approach:

  • The algebraic structure of a solution is immediately visible from the vanishing pattern of the Weyl and Ricci scalars;
  • Peeling properties and gravitational radiation are naturally expressed through ;
  • Many exact solutions — particularly those of Petrov types D and N — are most easily derived or classified within this framework;
  • The formalism interfaces cleanly with spinor calculus and twistor theory.

Workflow

Using SageMath and SageNP

SageNP is a Python/SageMath class that performs Newman–Penrose calculations on top of SageManifolds. Every metric in this database has been processed through SageNP; the same workflow reproduces all listed NP quantities. The package is available on PyPI: pypi.org/project/SageNP and on GitHub.

Installation

pip install SageNP

Conventions

  • Metric signature: (−,+,+,+).
  • Null tetrad labels follow the literature: (l, n, m, mbar). In Stephani's book the same vectors are written (k, l, m, mbar), so one identifies k → l and l → n when comparing formulas.
  • Non-vanishing inner products: ℓ·n = −1, m·m̄ = 1, all others zero.
  • Metric reconstruction from covariant tetrad vectors: g = −2 ℓ₍ₘnᵥ₎ + 2 m₍ₘm̄ᵥ₎.

Basic usage

A minimal end-to-end session for the Schwarzschild metric looks like this:

from SageNP import NewmanPenrose

# Manifold and coordinates
MyManifold    = Manifold(4, 'MyManifold', r'\mathcal{Man}')
MyCoordinates.<t,r,th,ph> = MyManifold.chart(r't r th:\theta ph:\phi')

# Metric functions
var('M')
Delta = r^2 - 2*M*r

# Null tetrad (covariant, ordering matches coordinates)
lvec    = [1, -(r^2)/Delta, 0, 0]
nvec    = [Delta/(2*r^2), 1/2, 0, 0]
mvec    = [0, 0, (-r/sqrt(2)), (-I*r/sqrt(2))*sin(th)]
mbarvec = [0, 0, (-r/sqrt(2)), ( I*r/sqrt(2))*sin(th)]

# Build the NP object (use 'contravariant' if the vectors above are contravariant)
schw = SageNP(MyManifold, MyCoordinates, lvec, nvec, mvec, mbarvec, 'covariant')

On construction the class builds the metric and prints it to the screen — it is a good habit to verify that the displayed metric matches the one you intended.

What SageNP computes

The class exposes a consistent set of calculate and show methods, plus direct access to every quantity by name.

Tetrad check

  • test_nulltetrad() — verifies ℓ·n=−1, m·m̄=1 and that every other inner product vanishes.

Spin coefficients (book p. 75–76, Eq. 7.2)

  • calculate_spincoefficients(), show_spincoefficients()
  • Available by name: kappaNP, tauNP, sigmaNP, rhoNP, piNP, nuNP, muNP, lambdaNP, epsilonNP, gammaNP, alphaNP, betaNP and their conjugates (kappabarNP, …).

Directional derivatives (p. 43, Eq. 3.82)

  • DlNP(X) — derivative along ℓ.
  • DeltanNP(X) — derivative along n.
  • deltamNP(X), deltambarNP(X) — derivatives along m and m̄.

Commutators (p. 77, Eq. 7.6)

  • Deltan_Dl_commNP(X), deltam_Dl_commNP(X), deltam_Deltan_commNP(X), deltambar_deltam_commNP(X) return the right-hand sides of the commutation relations.

Curvature

  • Weyl tensor components (p. 38, Eq. 3.59): calculate_Weyl(), show_Weyl(). Access via Psi0NP, Psi1NP, Psi2NP, Psi3NP, Psi4NP.
  • Ricci components (p. 78, Eq. 7.10–7.15): calculate_Ricci(), show_Ricci(). Access via Phi00NP, Phi01NP, Phi10NP, Phi02NP, Phi20NP, Phi11NP, Phi12NP, Phi21NP, Phi22NP, LambdaNP.

Field equations and identities

  • NP (Ricci) equations (p. 79, Eq. 7.21): calculate_NPeq(), show_NPeq(). The 18 equations are stored as NPeq1 … NPeq18, each written in the form 0 = −LHS + RHS.
  • Bianchi identities (p. 81, Eq. 7.32): calculate_Bianchi(), show_Bianchi(). The 11 identities are stored as BI1 … BI11.

Petrov classification (Kramer p. 121 Eq. 9.6; p. 54 Eq. 4.19; Fig. 9.1)

  • Invariants I, J, K, L, N: calculate_PetrovinvINP(), calculate_PetrovinvJNP(), … Results in PetrovinvINP, PetrovinvJNP, PetrovinvKNP, PetrovinvLNP, PetrovinvNNP.
  • Petrov_frominvariants() — determines the Petrov type from I, J, K, L, N.
  • Petrov_fromWeyl() — determines it directly from the Ψᵢ.

Matter field equations

  • kleingordon(Phi, M2) — massive Klein–Gordon equation for a scalar Phi with mass squared M2 (ref.: G. Silva-Ortigoza, Rev. Mex. Fis. 4, 543 (1996)). Result stored in kgNP.
  • dirac(f1, f2, g1, g2, M2) — massive Dirac equation for a spinor with components (f1, f2, g1, g2) (ref.: Chandrasekhar, Mathematical Theory of Black Holes, Oxford, 1983, p. 544). Result stored in diracNP.

SL(2,C) tetrad transformations

Following Carmeli & Kaye, Ann. Phys. 99, 188 (1976):

  • type_A_transformation(z) / show_type_A_transformation()
  • type_B_transformation(z) / show_type_B_transformation()
  • type_C_transformation(z) / show_type_C_transformation()

Each transformation populates a parallel set of attributes (lNP_trA, nNP_trA, mNP_trA, mbarNP_trA, the transformed spin coefficients kappaNP_trA, rhoNP_trA, …, the transformed Weyl and Ricci components Psi0NP_trA, Phi00NP_trA, …), and the analogous _trB, _trC for the other two types.

Batch helpers

  • calculate_allNP() — runs calculate_spincoefficients(), calculate_Weyl(), calculate_Ricci(), calculate_NPeq(), calculate_Bianchi(), and Petrov_fromWeyl() in sequence.
  • show_allNP() — displays all of the above.
